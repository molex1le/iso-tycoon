# Iso Tycoon – Кофейня

Реалистичный бизнес-симулятор в браузере. Ты – директор маленькой кофейни в вымышленной стране с очень знакомыми законами. Задача – прожить один игровой год и не обанкротиться.

Тут важно не только варить кофе. Придут СЭС, пожарная, трудовая и налоговая. Нужно платить налоги, брать кредиты и отдавать их, нанимать бариста официально или «в конверте», отбиваться от конкурентов и разбираться с событиями: сломалась кофемашина, пришёл блогер, сосед жалуется на запах. У каждого решения своя цена, а честный путь не всегда самый лёгкий.

> Это ранняя версия для плейтеста. Нужны твои впечатления: что непонятно, что скучно, где нечестно.

## Как запустить

### 1. Установи Node.js

Скачай с [nodejs.org](https://nodejs.org) версию **LTS** и установи как обычную программу. Нужна версия 20 или новее.

Проверить: открой терминал (на Windows – «Командная строка» или PowerShell, на Mac – «Терминал») и введи:

```bash
node -v
```

Должна появиться версия, например `v22.11.0`.

### 2. Скачай игру

Вариант попроще: на этой странице нажми зелёную кнопку **Code** → **Download ZIP** и распакуй архив в любую папку.

Вариант для тех, у кого есть git:

```bash
git clone https://github.com/molex1le/iso-tycoon.git
```

### 3. Запусти

В терминале перейди в папку с игрой. Проще всего набрать `cd `, с пробелом в конце, перетащить папку в окно терминала и нажать Enter. Затем:

```bash
npm install
```

```bash
npm run dev
```

`npm install` нужен только в первый раз, он скачивает нужные файлы (около минуты). После этого в терминале появится адрес – открой в браузере:

**http://localhost:5173/**

Пока играешь, терминал не закрывай. Чтобы остановить игру, нажми в терминале `Ctrl+C`.

Лучше всего играть в Chrome, Edge или Firefox на компьютере, экран от 1280 px в ширину.

## Как играть

1. **Главное меню.** Выбери пустой слот и нажми «Новая игра». Слотов три, игра сохраняется сама каждый игровой день.
2. **Мастер старта:**
   - сложность: **Учебка** (с подсказками советника), **Реализм** или **Выживание**;
   - форма бизнеса (ИП или ООО) и налоговый режим;
   - район: спальный, у метро или центр;
   - оборудование;
   - первые бариста.

   Для первого раза советуем Учебку.
3. **Время.** 24 секунды – один игровой день. Пробел – пауза, клавиши `1`, `2`, `3` – скорость. На событиях и проверках игра сама встаёт на паузу.
4. **Карта.** Колесо мыши – приблизить, перетаскивание – сдвинуть. Клик по зданию открывает карточку: кофейня, банк, налоговая, склад, конкуренты.
5. **Вкладки внизу:**
   - цены, персонал, склад, техника;
   - банк и налоги, чек-листы проверок;
   - финансы, журнал;
   - вторая точка – открывается позже.
6. **Цель.** Дожить до 360-го дня. В конце будет итог года и медаль, потом можно играть второй год.

### Несколько советов

- В шапке есть **подушка в днях** – на сколько дней хватит денег. Если она тает, пора что-то менять.
- Плановые проверки приходят с предупреждением. Чтобы подготовиться, открой вкладку «Проверки».
- Декларацию и налог нужно подать и заплатить вовремя, иначе будут пени и блокировка счёта.
- Серые схемы экономят деньги, пока их не поймали.

## Как оставить отзыв

После партии (или когда надоест) открой меню ☰ в игре:

- **«Оставить отзыв»** – короткая форма, сохраняется файлом;
- **«Телеметрия CSV»** – файл с цифрами по каждому дню партии.

Пришли оба файла автору. Очень поможет, если коротко напишешь словами: что понравилось, что бесило и где ты не понял, что происходит.

## Если что-то не работает

| Проблема | Что сделать |
| --- | --- |
| `node` или `npm` не найдены | Node.js не установлен. Установи и **перезапусти терминал**. |
| `npm install` выдаёт ошибки | Проверь, что ты в папке игры: в ней лежит файл `package.json`. |
| Адрес не открывается | Терминал с `npm run dev` должен оставаться открытым. |
| Порт 5173 занят | Vite сам возьмёт другой порт – смотри адрес в терминале. |
| Пропало сохранение | Сохранения лежат в браузере. Другой браузер или режим инкогнито их не видит. |

## Для разработчика

| Команда | Что делает |
| --- | --- |
| `npm test` | тесты ядра и карты |
| `npm run build` | сборка в `dist` |
| `npm run balance` | 1 000 партий ботами на каждую сложность (Mac и Linux) |

Режим разработчика открывается адресом `http://localhost:5173/?dev`: в нём есть кнопка DEV, деньги, проверки, события и готовые сценарии.

Подробнее:

- [docs/REPORT.md](docs/REPORT.md) – как всё устроено и считается;

Стек: Vite, TypeScript, Vitest. Логика игры лежит в `src/core` и не зависит от интерфейса. Все числа баланса и тексты – в `src/data`.
