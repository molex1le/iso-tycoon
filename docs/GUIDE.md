# Iso Tycoon – инструкция

## Как запустить

Нужен Node.js 20 или новее. В папке проекта:

```bash
npm install
npm run dev
```

Игра откроется по адресу http://localhost:5173/.

| Адрес | Что это |
| --- | --- |
| `http://localhost:5173/` | режим игрока: отладки нет совсем |
| `http://localhost:5173/?dev` | режим разработчика: кнопка DEV в шапке |
| `http://localhost:5173/?seed=7` | партия с заданным сидом (одинаковая случайность) |
| `http://localhost:5173/?dev&seed=7` | оба сразу |

Другие команды:

| Команда | Что делает |
| --- | --- |
| `npm test` | тесты ядра (113 штук) |
| `npm run build` | сборка в папку `dist` |
| `npm run balance` | 1 000 партий ботами на каждую сложность |

## Как играть

1. **Главное меню.** «Новая игра» открывает мастер старта, «Продолжить» – последнюю партию (игра сохраняется сама каждый день).
2. **Мастер старта.** Выбираете сложность, форму (ИП или ООО), налоговый режим, место на карте (спальный район, у метро, центр), оборудование, оформление первых бариста (официально или «в конверте»).
3. **Экран игры.** Сверху шапка: деньги, прибыль за день, подушка в днях, репутация, дата, погода, скорость. Внизу панель вкладок.
4. **Время.** 24 секунды = 1 день. Пробел – пауза, клавиши 1 / 2 / 3 – скорость. На событиях и проверках игра сама встаёт на паузу.
5. **Карта.** Колесо – зум, перетаскивание – движение. Клик по кофейне, банку, налоговой, складу, конкуренту открывает карточку.
6. **Цель.** Дожить до 360-го дня и не обанкротиться. После итога можно играть следующий год.

### Вкладки

| Вкладка | Что там |
| --- | --- |
| Зал | вид кофейни изнутри, очередь, чистота |
| Обзор | главные цифры, графики, советник (только в «Учебке») |
| Финансы | доходы и расходы по месяцам |
| Цены | цены на напитки и средний чек |
| Люди | бариста: наём, увольнение, оформление, усталость, лояльность |
| Склад | запасы, поставщик, списание |
| Проверки | чек-листы СЭС, пожарной, трудовой, налоговой |
| Техника | оборудование и ремонт |
| Банк | кредиты, налоги, декларация |
| Сеть | вторая точка (с 90-го дня, репутация от 3,5) |
| Сроки, Журнал | ближайшие даты и лента событий |
| Потоки | откуда идут люди и какая у кого доля |

### Проверки

Плановые приходят с уведомлением: СЭС – день 75, пожарная – 165, налоговая – 255, трудовая – 315. Внеплановые – по жалобам и доносам. На проверке инспектор задаёт вопросы, на каждый можно ответить по-разному (признать, спорить и т. д.), затем выбрать: принять штраф, оспорить или дать взятку. Готовиться заранее – во вкладке «Проверки».

## Режим разработчика

Откройте игру с `?dev` в адресе. В шапке появится кнопка **DEV** (или клавиша F2, на Mac – Fn+F2). В панели:

- **Деньги:** + $1 000, + $10 000, − $5 000.
- **Репутация:** поставить 2, 3, 4 или 5 звёзд.
- **Погода:** ясно, дождь, снегопад, жара.
- **Проверка сейчас:** любая из четырёх служб.
- **Событие:** выбрать из списка (49 штук) и запустить.
- **Новый конкурент:** начать стройку новой кофейни.
- **Перемотка:** +1, +7, +30, +90 дней. Отчёты, события и проверки по пути закрываются сами (первый вариант ответа, штраф принимается).
- **Готовые сценарии:**

| Сценарий | Что получится |
| --- | --- |
| Перед проверкой СЭС | день 70, до визита 5 дней |
| Новый конкурент строится | день 180 и стройка рядом |
| Можно открыть вторую точку | день 95, репутация 4, не меньше $25 000 |
| Конец года | день 358, через два дня итог |
| На грани банкротства | день 40, на счёте −$500 |
| Налоговая проверка | день 250, до плановой 5 дней |

Сценарий перематывает текущую партию вперёд. Если нужный день уже прошёл, кнопка неактивна – начните новую игру. Сценарии лежат в `src/data/devScenarios.json`, их можно дописывать без кода.

## Где что править

| Что | Файл |
| --- | --- |
| Все числа баланса | `src/data/balance.json` |
| События | `src/data/events.json` |
| Проверки и инспекторы | `src/data/inspections.json`, `src/data/inspectors.json` |
| Диалоги на проверках | `src/data/dialogues.json` |
| Тексты ленты, подсказки, обучение | `src/data/texts.json`, `tips.json`, `tutorial.json` |
| Логика | `src/core/` (без интерфейса, покрыта тестами) |
| Интерфейс и карта | `src/ui/` |

После правки баланса запускайте `npm run balance` и сравнивайте проценты выживших с целями из отчёта.

## Сохранения и отзывы

- Автосохранение – в браузере, каждый игровой день.
- Меню (☰) → «Скачать сейв» – файл партии; «Загрузить сейв из файла» – в главном меню.
- Меню → «Телеметрия CSV» – строка на каждый день, для разбора партии.
- Меню → «Оставить отзыв» – форма для плейтеста, сохраняется файлом.
